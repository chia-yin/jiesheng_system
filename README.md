# 杰升考勤系統

公司簡易打卡考勤系統。

## 功能

- 上班 / 下班打卡
- 今日打卡摘要
- 依日期查詢紀錄

## 本機開發

```bash
npm install
npm run dev
```

開啟 http://localhost:3000

## Cloud 開發

1. 前往 [Cursor Cloud Agents](https://cursor.com/dashboard/cloud-agents)
2. 建立 environment，選擇 `jiesheng_system` repo
3. Agent 選 **Cloud** 繼續開發

詳見 `AGENTS.md`。
